# HanokJIN
한옥의 도면을 업로드하면, 3D 모델로 만들어주는 애플리케이션입니다.

DWG·DXF 평면도를 열면 격자(주열)와 기둥을 찾아 한옥 3D 모델을 만들고, 사람이 인식 결과를 확인·수정한 뒤 색감을 골라 BIM(IFC)·3D(glTF)·평면(DXF)·물량표(CSV)로 내보냅니다.

```
도면 준비 → 인식 검토 → 3D 생성 → 꾸미기·편집 → 내보내기
```

## 시작하기

Node.js 20 이상이 필요합니다.

```bash
npm install
```

```bash
npm run dev
```

브라우저에서 `http://localhost:5173`을 열고 도면 파일을 끌어다 놓거나, 예제 프로젝트로 둘러보세요.

| 명령 | 설명 |
| --- | --- |
| `npm run dev` | 개발 서버 |
| `npm run build` | 타입 검사 + 배포용 빌드(`dist/`) |
| `npm test` | 단위 테스트 |
| `npm run typecheck` | 타입 검사만 |

실제 DWG로 인식 테스트를 돌리려면 파일 경로를 환경변수로 줍니다(고객 도면은 저장소에 넣지 않습니다).

```bash
HANOK_TEST_DWG="/path/to/도면.dwg" npm test
```

## 화면 구성

- **기본 화면**: 도면과 3D 모델만 나란히 보입니다. 머리글의 `도면 | 나란히 | 3D`로 한쪽만 크게 볼 수 있고, 가운데 경계를 끌어 비율을 바꿉니다.
- **꾸미기·설정(오른쪽 서랍)**: 평소엔 닫혀 있습니다.
  - 색감: 백골 민가 · 궁궐 단청 · 고택 먹빛 · 현대 한옥 프리셋, 재료별 색 직접 지정
  - 형태: 지붕 형식(팔작·우진각·맞배), 기둥·지붕 높이, 처마 길이, 앙곡, 공포, 량가, 흘림, 창살
  - 고급: 안허리곡, 기단 높이, 주경 D, 결구 유격, 도면 인식 정보, 도면 값으로 되돌리기
  - 값마다 출처(`도면` / `기본값` / `수정함`)와 쉬운 설명, 허용 범위 검사가 있습니다.
- **도면 창**: 원본 CAD 선 위에 인식한 격자·기둥·외벽 칸을 겹쳐 보여 줍니다. 기둥·외벽 칸 클릭으로 선택, `기둥 추가`(격자 교차점에 맞춤), `축척 보정`(두 점 + 실제 길이), 시트 전환(평면·지붕·앙시·입면·단면), 레이어 켜고 끄기.
- **3D 창**: 시점 프리셋(조감도·정면·측면·배면·지붕 위), 부재 클릭 선택, `구조 보기`(부재 묶음 표시/숨김), `결구 구조 살펴보기`(8단계 분해·조립 재생), `단면 보기`(X·Y·Z).
- **아래 요약 줄**: 기둥 수, 검토 필요, 목재 재적, 기와(추정), 검증 상태. 누르면 `검증 결과 / 물량 명세서(BOM) / 결구 상세`가 열립니다.
- 실행 취소/다시 실행(Ctrl+Z / Ctrl+Y), 삭제 전 확인, 이 브라우저 안 자동 저장(새로고침 후 이어서 작업).

## 구조

```
src/
  cad/        도면 읽기와 인식
    dwg-reader.ts   DWG 어댑터(LibreDWG WebAssembly) — 엔진 교체 지점
    dxf-reader.ts   ASCII DXF 파서(자체 구현, CP949·\U+ 한글 처리)
    normalize.ts    블록 펼치기·곡선 선분화 → 정규화 문서(CadDoc)
    sheets.ts       한 모델 공간의 여러 시트 분리·종류 분류
    recognize.ts    격자·기둥·실·창호·높이·부재 표기 인식
    worker.ts       해석은 Web Worker에서(화면 멈춤 없음)
  model/      한옥 3D 생성
    footprint.ts    기둥 배치 → 외곽 칸 → 채(날개) 분할
    roof.ts         팔작·우진각·맞배 지붕면(앙곡·안허리곡)
    hanok.ts        기단·기둥·공포·보·도리·서까래·벽·창호·지붕 + 물량 집계
    validate.ts     검증(간섭·경간·처마 각도·물매 등)
    palettes.ts     색감 프리셋
  export/     IFC4 · glTF(.glb) · DXF · CSV
  ui/         도면 창, 3D 창, 설정 서랍, 아래 패널, 대화상자
  app/        상태(되돌리기), 자동 저장, 조립
tests/        DXF 왕복·인식, 모델·IFC, 실제 DWG(선택)
```

## 인식은 어떻게 하나요

규칙 기반이며, 찾은 값마다 근거와 신뢰도를 남깁니다. 확실하지 않은 항목은 노란 `!`로 표시해 사람이 확인하게 합니다.

| 항목 | 근거 |
| --- | --- |
| 시트 | 도형 연결 덩어리 + 제목 글자(평면도, 지붕 평면도, 앙시도, 정면도…) |
| 격자 | 주열 번호(X1, Y1…)와 그 원(버블) 중심, 근처 중심선. 없으면 기둥 위치 군집 |
| 기둥 | 격자 교차점 근처의 원(원주)·사각형(방주, 폴리라인 또는 선 4개). 동심원은 가장 안쪽을 기둥으로 |
| 실 | 평면 안의 실 이름 글자(안방, 대청, 거실, 주방…) → 바닥 재료 |
| 창호 | 외벽 칸 근처의 `창/문` 이름표, 창호 레이어의 창살 선 |
| 높이 | 입면도 세로 치수 체인 → 기단 / 기둥 / 지붕 |
| 처마 | 지붕 평면도 외곽과 격자의 차이 |
| 부재 | `270X330 대량`, `Ø120 연목` 같은 표기 |

담양 32평 ㄱ자형 DWG(AutoCAD R14, 시트 8장)에서 격자 X1~X5 × Y1~Y5(0/4,200/6,900/9,600/13,200 · 0/3,600/6,600/9,600/12,600mm), 기둥 15개, 기단 550·기둥 2,550·지붕 3,240mm, 대량 270×330 등을 찾고, 바닥 면적이 도면 표기 건축 면적 106.92㎡와 일치합니다.

## 실제 값과 추정 값

- 물량(BOM)은 실제로 만든 부재에서 셉니다. 기와 매수는 지붕 실면적에서 낸 **추정**이며 근거(골 간격 등)를 함께 표시합니다.
- 구조 검토는 전통 목구조 경험식에 따른 **참고 판정**이며 구조계산을 대신하지 않습니다.
- 예제 프로젝트는 화면 곳곳에 `데모 데이터`로 표시합니다.

## 아직 안 되는 것

- PDF·이미지(스캔) 도면 인식
- 바이너리 DXF, AutoCAD R12 이하 DWG
- 실내 칸막이벽, 2층 이상, ㄱ·ㄷ·ㅁ 외의 복잡한 평면 지붕(근사 처리)
- 공포·결구의 실제 가공 형상(설명용 형상으로 표시)

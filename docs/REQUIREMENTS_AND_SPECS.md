# HanokJIN — 4면 사진\[전·후·좌·우\] 기반 3D 모델링 및 사실적 PBR 렌더링 명세서

본 문서는 **HanokJIN** 프로젝트에 새롭게 추가되는 **1) 건물 4면\[전·후·좌·우\] 지정 프레임 촬영 기반 3D 한옥 모델 자동 생성 기능**과 **2) 텍스처·조명(PBR)을 반영한 사실적인 건물 3D/UI 색상 개선**에 대한 요구사항(Requirements), 유스케이스(Use Cases), 상세 기능 명세(Functionality) 및 아키텍처 설계를 정의합니다.

## 1. 개요 및 배경 (Background & Objectives)

기존 **HanokJIN**은 CAD 도면(`DWG`, `DXF`)을 업로드하여 주열(격자)과 기둥을 인식하고 한옥 3D 모델을 생성하는 워크플로우를 제공했습니다. 그러나 실제 현장 답사나 기존 건축물 기록 작업에서는 CAD 도면이 없거나, 스마트폰·태블릿 카메라로 건물의 4면(정면·배면·좌측면·우측면)만 촬영해 빠르게 3D 매스 및 부재 모델을 구축해야 하는 요구가 높습니다.

또한 기존 3D 뷰포트와 UI의 재료 색상은 128px 수준의 단순 회색조 캔버스 텍스처에 단색(`MeshStandardMaterial.color`)만 곱하고 법선/요철(`bumpMap`/`normalMap`)이나 환경광 반사(`PMREM Environment Map`)가 없어, 빛의 방향과 표면 질감이 살아나지 않고 플라스틱 같은 단색으로 보이는 한계가 있었습니다.

이를 해결하기 위해 다음 두 가지 핵심 축을 설계·구현합니다.

1. **4면 \[전·후·좌·우\] 지정 프레임 촬영 → 3D 모델 생성 (`src/photo/photo-modeler.ts`, `src/ui/photo-modal.ts`)**

   * 정면(Front/남), 배면(Rear/북), 좌측면(Left/서), 우측면(Right/동) 4개 시점에 맞춘 지정 가이드 프레임(Guide Frame Overlay)을 제공하고, 촬영 또는 업로드된 4면 사진으로부터 기단·기둥·지붕 비례, 기둥 열(칸 수), 지붕 형태(팔작·우진각·맞배), 개구부(창호·문) 및 실제 외관 색감을 추출하여 즉시 편집·내보내기 가능한 한옥 3D 모델(`Project`)을 생성합니다.

2. **사실적인 건물 3D 재질(PBR) 및 UI 재질 표현 고도화 (`src/model/textures.ts`, `src/model/materials.ts`, `src/model/palettes.ts`, `src/ui/viewport.ts`)**

   * 고해상도 절차적 알베도(Albedo) + 범프/노멀(Bump/Normal) + 거칠기(Roughness) 맵과 절차적 HDRI 환경광(IBL), 시간대별 자연광(아침·정오·석양·흐림) 조명을 도입하고, 우측 인스펙터의 색상 스와치 역시 빛과 질감이 반영된 3D 재질 구체(Material Sphere Chip)로 개선합니다.

## 3. 유스케이스 명세 (Use Cases)

### 3.1 유스케이스 다이어그램 및 액터

* **주요 액터 (Primary Actor)**: 한옥 설계자, 현장 조사자(실측자), 건축주/학생

* **핵심 유스케이스**:

  * **UC-01**: 건물의 4면\[전·후·좌·우\]을 지정 프레임에 맞춰 촬영/업로드하여 3D 한옥 모델 생성

  * **UC-02**: 4면 가이드 프레임 기준선(기단·처마·용마루·칸 수) 보정 및 지붕/개구부 자동 인식 검토

  * **UC-03**: 사실적 PBR 재질 프리셋 및 시간대별 자연광 조명(정오·아침·노을·흐림) 시뮬레이션

  * **UC-04**: 생성된 3D 모델의 BIM(IFC4) / glTF(.glb) / DXF 평면도 / 물량산출서(CSV) 내보내기

### 3.2 상세 유스케이스 흐름 (UC-01 & UC-02: 4면 사진 촬영 기반 3D 모델링)

1. **진입 (Trigger)**

   * 사용자가 시작 화면 또는 상단 헤더에서 **`[4면 사진으로 3D 만들기]`** 버튼을 클릭한다.

2. **4면 \[전·후·좌·우\] 사진 입력**

   * 모달 창 좌측에 **\[1. 정면(남)\]**, **\[2. 배면(북)\]**, **\[3. 좌측면(서)\]**, **\[4. 우측면(동)\]** 탭이 표시된다.

   * 사용자는 각 면에 대해 **(A) 실시간 카메라 촬영**(`카메라 켜기` → 화면 중앙의 한옥 가이드 프레임에 건물을 맞춘 뒤 `이 프레임으로 촬영`) 또는 **(B) 사진 파일 업로드** 중 하나를 선택한다.

3. **지정 프레임 정렬 및 자동 분석**

   * 각 면 사진 위에는 지정된 프레임 오버레이가 표시된다:

     * **수평 기준선 3개**: 용마루선(`ridgeY`), 처마/기둥머리선(`eaveY`), 기단 상단선(`gidanY`), 지면선(`groundY`)

     * **수직 기준선**: 좌측 외곽 기둥선(`leftX`), 우측 외곽 기둥선(`rightX`) 및 칸(주열) 분할선

   * 시스템은 이미지의 수평/수직 에지 히스토그램과 색상 영역을 분석하여 기준선 초기 위치, 칸별 창호/문/벽 종류, 그리고 기둥·벽·기와의 실제 색상을 자동 추출한다.

   * 사용자는 필요 시 이미지 위의 프레임 핸들을 마우스/터치로 끌어 기단·처마·용마루 높이나 정면/측면 칸 수(예: 정면 5칸 × 측면 2칸) 및 기준 길이(예: 정면 총장 13,800mm 또는 어칸 3,000mm)를 보정한다.

4. **3D 모델 합성 및 생성**

   * 사용자가 **`[4면 분석으로 3D 한옥 생성]`** 버튼을 누르면:

     * 정면·배면 프레임의 수직 비율과 기준 길이로부터 `gidanHeight`, `pillarHeight`, `roofHeight`, `eaves`, `anggok`을 산출한다.

     * 정면·배면 칸 분할선에서 `grid.xs`를, 좌·우측면 칸 분할선에서 `grid.ys`를 생성하고 외곽 및 내부 기둥(`pillars`)을 배치한다.

     * 4면 각 칸의 분석 결과에 따라 정면(S)·배면(N)·좌측면(W)·우측면(E) 개구부(`openings`: 문/창호/벽)를 배치한다.

     * 사진에서 추출한 실제 색감(또는 선택한 전통 재질 팔레트)을 적용하여 `Project`와 2D 평면도(`CadDoc`)를 생성하고 3D 뷰포트를 연다.

## 4. 기능 상세 설계 (Detailed Functionality & Architecture)

### 4.1 4면 지정 프레임 3D 복원 알고리즘 (`src/photo/photo-modeler.ts`)

```
[정면(Front) 사진 + 프레임] ──► 정면 주열(xs), 기단·기둥·지붕 높이비, 남측(S) 창호/문, 대표 색상 추출 ─┐
[배면(Rear)  사진 + 프레임] ──► 배면 높이 교차검증, 북측(N) 창호/문/벽 판별                         ├─► 3D Project + 2D CadDoc 생성
[좌측(Left)  사진 + 프레임] ──► 측면 주열(ys), 처마 내밀기, 박공/합각(지붕 형식), 서측(W) 창호/문   │
[우측(Right) 사진 + 프레임] ──► 측면 주열 교차검증, 동측(E) 창호/문/벽 판별                         ┘

```

1. **지정 프레임 데이터 구조 (`PhotoFrameGuide`)**

   * 정규화 좌표(`0.0 ~ 1.0`) 기반으로 이미지 해상도에 무관하게 동작:

     * `ridgeY`: 용마루 상단 Y 비율 (기본 `0.20`)

     * `eaveY`: 처마/주심도리 하단 Y 비율 (기본 `0.48`)

     * `gidanY`: 기단 상단(기둥 밑동) Y 비율 (기본 `0.80`)

     * `groundY`: 지면 기준선 Y 비율 (기본 `0.88`)

     * `leftX`, `rightX`: 좌·우 양 끝 귀기둥 중심선 X 비율 (기본 `0.14`, `0.86`)

     * `bays`: 해당 면의 칸 수 (정면/배면 기본 3\~5칸, 좌/우측면 기본 2\~3칸) 및 각 칸의 개구부 유형(`door` | `window` | `solid`)

2. **이미지 자동 특징 추출 (`analyzePhotoCanvas`)**

   * 촬영/업로드된 이미지를 오프스크린 Canvas(`256×256`)에 그린 뒤 Sobel 수평/수직 에지 프로파일과 영역별 평균 색상을 계산합니다.

   * **높이 비율 역산**:
     

     $$
     \text{기둥 실제 높이 } H_{\text{pillar}} = L_{\text{ref}} \times \frac{\text{eaveY} - \text{gidanY}}{\text{rightX} - \text{leftX}}
     $$

     $$
     \text{기단 높이 } H_{\text{gidan}} = H_{\text{pillar}} \times \frac{\text{groundY} - \text{gidanY}}{\text{gidanY} - \text{eaveY}}, \quad \text{지붕 높이 } H_{\text{roof}} = H_{\text{pillar}} \times \frac{\text{eaveY} - \text{ridgeY}}{\text{gidanY} - \text{eaveY}}
     $$

   * 얻어진 치수는 `params.ts`의 한옥 전통 비례 허용 범위(`clampParam`) 내로 안전하게 보정됩니다.

   * **칸별 개구부 인식**: 기둥 사이 각 칸의 중하단 영역 밝기/대비를 분석하여 창호지(밝은 한지 톤 + 격자 고주파 에지)와 출입문(중앙 칸 또는 바닥까지 내려오는 개구부), 회벽을 자동 분류합니다.

   * **외관 팔레트 추출**: 지붕 영역(`ridgeY ~ eaveY`), 벽 영역(`eaveY ~ gidanY`), 기둥 경계선, 기단 영역(`gidanY ~ groundY`)에서 채도·명도가 보정된 대표 색상을 샘플링하여 `'photo-custom'` 팔레트로 적용할 수 있게 합니다.
